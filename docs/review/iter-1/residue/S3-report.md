## 4. What changed that a reader of the code or a script needs to know

- **Readouts** (plain text, ASCII minus; the brief asks for `2πk` rather than `2*pi*k` where the tests can still read the values):
  - powers: `zⁿ = 512 - 886.81i; |z|ⁿ = 1024; nθ = 5.236 (5π/3); home step = -1.047 (-π/3)` (it was `z^n`, `|z|^n`, `n*theta`); `#powers-angle` reads `nθ = 5π/3 (5.236 rad): one name of arg(zⁿ), not the home step` and the other two modes use `π`; the chain lines read `z² = (1.732 + i)(1.732 + i) = 2 + 3.464i`; tiny and huge numbers read `2.441×10⁻⁴`.
  - staircase sum: `Arg z₁ + Arg z₂ = 4.712 (3π/2); Arg(z₁z₂) = -1.571 (-π/2); differ by 1·2π` (the same z₁, z₂ as the labels).
  - linear: the readout is set with `prose()`, so `e^(i 1.571)` is a superscript; the text is what `readoutText` returns.
  - linear stage caption: the strings of entry 3.
- **New named exports** (for tests): `curves.js`: `COPY`, `TAKEAWAY`, `endpointSides`; `linear.js`: `COPY`, `spotsAround`; `powers.js`: `tickBoxes`, `spotsAround`, `plainProse`. `pickSpot` takes `obstacles.soft`; `drawAngleArcs` takes `ghostDash`; `handleBox` and `placeOrientLabel` take a `side` and a `ring`. None is in an ARCHITECTURE section, so `architecture-sync` is unaffected.
- **Interaction scripts**: `tests/interact/i1-station-curves-linear.mjs` now exports `canvasWords` (records the `fillText`, `arc`, `moveTo`/`lineTo` calls of one forced redraw of a plane: words, dots, 8 px axis marks), `assertWordsClear` and `noBraces`; the staircase and powers script imports them. They need nothing from `_helpers.mjs` that was not there.
