## What still makes the test feel daunting (asks for iteration 2, highest impact first)

1. **Rehearsal, not recognition.** The site explains the 29 handout problems; the test will use
   different numbers. Add a rehearsal mode: a fresh variant of each problem type (new numbers, same
   shape), where the student first picks the address, predicts the picture (drag a guess), then sees
   the station's picture and the worked numbers. This is the most direct answer to "make the test
   questions feel less daunting".
2. **Videos and narration (media track).** No manim videos or station narration exist yet. Plan
   4–6 short narrated explainers that carry the spine (place and move; the staircase and roots;
   a function is a motion; zoom and Cauchy–Riemann; the 4D shadows) plus narration scripts for the
   busiest stations. Narration text is written in the loop; audio is generated by the local agent
   (ElevenLabs via OpenRouter, approved up to 10 runs a day).
3. **One path through 21 stations.** The night-before plan on home exists; make it a guided path
   with progress (each stop: one interaction, one problem, one sentence to say out loud), so the
   site never feels like 21 tabs.
4. **The Lab's diary feeling.** Make the image ink itself in step with the stroke while drawing
   (not only after release), and add a "replay my stroke" scrub that shows input and output being
   drawn by the same clock. Verify the live behaviour in an interaction script.
5. **Identity.** The look is clean but close to a generic default (cream page, serif headings).
   A subject-grounded identity (navigation chart / astrolabe: the polar grid as the visual motif)
   would make the site more memorable. Lower priority than 1–4.
6. **Shared station pieces.** Problem cards, neighbour links and headers are built per station and
   differ slightly (left bar vs top bar). Build the shared station-kit / problem-card modules
   (docs/review/iter-1/residue/D-report.md, "Open for iteration 2").
